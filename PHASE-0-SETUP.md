# Phase 0: setup

updated: 2026-08-29

## Goal

A running local dev server with nothing in it yet, committed to git.

## Steps

1. `git init` in this folder.
2. Scaffold Vite + React + TypeScript.
3. Add Tailwind.
4. Add the fairytale look: Google Fonts (a display serif and a script for headings), the palette (blush pink, gold, lavender, deep plum on cream), defined once as design tokens.
5. Dev server runs, blank shell with the app title renders on desktop and mobile widths.

## Done when

Dev server verified in the browser at mobile and desktop sizes, first commit made.
